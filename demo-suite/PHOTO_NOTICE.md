# 演示肖像来源 / Demo portrait credits / デモ用選手写真の出典

## 简体中文

本项目以 M.League 官网公开的选手名、队伍名和肖像制作独立演示。三份赛事中的对局、成绩、进度、排名和选手统计均为模拟，演示的赛事和队伍编排用于展示软件功能。照片及相关权利归各自权利方，肖像使用适用各权利方的条款。项目的 MIT 许可适用于项目自有内容。[M.League 官网队伍页](https://m-league.jp/teams/)

团队赛 JSON 内嵌 40 张肖像，个人积分赛和个人淘汰赛 JSON 各内嵌 16 张。每张肖像的原图链接、官网来源页、选手和队伍见名册 `roster.json`。在仓库中可于 `resources/demo/roster.json` 查看原始名册。

官网粉丝创作指引说明了相关权利及粉丝活动示例。随软件、演示文件复制或分发官网原照的许可需单独核实。本仓库记录来源，当前未收录此类分发授权。[M.League 粉丝创作指引（2024 年 6 月 26 日）](https://m-league.jp/news202406261200/)

## English

These independent software demos use names, teams, and official portraits sourced from the M.League website. All demo matches, scores, progress, rankings, and player statistics are simulated. The respective rights holders retain rights in the portraits and other league material. The project’s MIT license applies to its own contributions. [M.League team directory](https://m-league.jp/teams/)

The team league JSON embeds 40 portraits. The individual league and knockout JSON files embed 16 portraits each. `roster.json` records the player, team, profile page, and image URL for each portrait. In the source repository, the catalogue is at `resources/demo/roster.json`.

The official fan activity guidelines describe relevant rights and examples of fan activity. Confirm permission separately before redistributing official portraits with software or demo files. This repository records the sources. It has no documented grant covering that redistribution. [M.League fan activity guidelines](https://m-league.jp/news202406261200/)

## 日本語

この非公式デモには、Mリーグ公式サイトに掲載された選手名、チーム名、選手写真を使用しています。対局、得点、進行状況、順位、選手成績はすべてデモ用のシミュレーションです。写真などの権利は各権利者に帰属し、MIT ライセンスは本プロジェクトの独自制作部分に適用されます。[Mリーグ公式チーム一覧](https://m-league.jp/teams/)

チーム戦の JSON には写真が 40 枚、個人リーグ戦と個人トーナメント戦の JSON にはそれぞれ 16 枚含まれています。各写真の選手名、所属チーム、掲載ページ、画像 URL は名簿 `roster.json` に記録しています。ソースリポジトリでは `resources/demo/roster.json` にあります。

公式ガイドラインには関連する権利とファン活動の例が記載されています。公式写真をソフトウェアやデモファイルに含めて再配布する場合は、許諾の範囲を別途確認してください。このリポジトリには出典を記録しており、当該再配布の許諾を示す記録はありません。[ファンアートの取り扱いに関するガイドライン](https://m-league.jp/news202406261200/)
