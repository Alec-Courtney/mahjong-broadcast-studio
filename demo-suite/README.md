# 演示赛事

## 下载后导入

运行 `START-Windows.cmd`，在「赛事管理 → 赛事库」点击「导入完整赛事 JSON」，选择以下任一文件。导入会新增一场独立赛事。选手肖像已内嵌在 JSON 中。[项目启动说明](../README.md#快速开始)

| 文件 | 可体验的内容 |
| --- | --- |
| [团队积分赛](team-league-demo.json) | 10 队 40 人，已归档 50 个半庄。可比较队伍积分、个人表现和各半庄的点数走势，并继续当前对局。 |
| [个人积分赛](individual-league-demo.json) | 16 人，已归档 20 个半庄。可查看个人排名、逐局记录及技术统计，并继续当前对局。 |
| [个人淘汰赛](individual-knockout-demo.json) | 16 人、3 轮、7 桌，每桌 4 个已归档半庄。可查看对阵表、各轮晋级和冠军。 |

三套演示采用原有的 M.League 队伍、选手名和官网肖像。成绩、逐局记录和技术统计来自计分引擎的模拟对局。三份演示覆盖全部 25 项可选技术统计。两种积分赛的每名选手都有 5 个已归档半庄的记录。也可直接打开赛事库内置的「【演示】M.League 团队积分赛」。[肖像权利说明](PHOTO_NOTICE.md) · [逐张来源名册](../resources/demo/roster.json)

## 推荐顺序

1. 01团队联赛：打开榜单与导出，切换个人/团队榜；在播出中查看红色四队侧榜及底部队伍积分。
2. 03个人联赛：查看每人已打/总场次，应用ML完整数据和技术统计预设。
3. 06—10淘汰赛：从未开赛、进行中到全程完成，比较四进一/二/三与种子直入。07可继续打当前半决赛的第二场；09可直接演示南四晋级条件。
4. 11听牌对照：四席分别展示普通有役、混合无役、振听与无役振听，包含0和未填写山存。
5. 12统计缺失：对照可靠基数、未知数据和只补录结果，未知比率显示“—”。
6. 13报表：所有技术列、自定义表头、调序、Excel及完整PNG导出。
7. 15—26原有场景：检查开局、各类副露、五宝牌、长名字、同分/负分、单倍/双倍役满及支付动画。

## 文件与使用

- `library/`：可直接启动并继续操作的独立赛事库。
- `portable/`：每场完整JSON，内嵌照片，可在正式软件中“导入为独立赛事”。
- `exports/`：预先生成的彩色Excel、个人/团队PNG、晋级图和播出模块示例。
- `catalog.json`：场景和功能覆盖目录。
- `validation.json`：校验结果。

## 操作提示

- 本场未到终局前，正式榜单保持开场前已确认数据；终局点击“记录本场积分”才更新。
- 已经结束的场景可切换最终点数/结算pt，重播图表；要重新看支付动画，可在内置演示页载入对应场景后点击重播。
- 工作台“榜单与导出”的预设、列设置、表头改名会保存到当前演示赛事。
- 多次操作不会改动 `portable/` 中的初始JSON，想恢复某个场景可将该JSON重新导入为独立赛事。
- `legacy_m_tournament` 复现一个公开积分局面，其余场景的比赛过程和结果为模拟数据。

正式赛事仍通过原 `START-Windows.cmd` 打开。
