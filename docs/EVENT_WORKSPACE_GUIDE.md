# 多赛事工作台与成绩发布

通过导播台的「赛事管理」配置赛事、安排半庄、确认成绩和导出榜单。设置入口及资料保存位置见对应说明。 [设置与赛事入口](SETTINGS_NAVIGATION.md) · [赛事数据与备份](EVENT_DATA_STORAGE.md)

## 开始使用

首次通过 `START-Windows.cmd` 打开新赛事库时，会加入「【演示】M.League 团队积分赛」。这场独立赛事使用 40 名官网名册中的选手和肖像，包含 50 个已确认的模拟半庄，可在赛事库切换或查看历史成绩。也可导入另一个演示赛事。[演示 JSON 与导入步骤](../demo-suite/README.md#下载后导入)

双击项目根目录 `START-Windows.cmd`。导播台提供 **赛事管理**、**半庄管理**、**排名与结果** 和 **系统设置**。现场计分、待牌、副露、局况、术语和场景可在导播台操作。赛事规则和播出配置在赛事工作台管理。

只需要转播 UI 时，双击 `START-UI-Only.cmd`。独立导播会保存到 `data/standalone/`，不载入比赛数据；选手资料、点数录入、听牌、副露和播出设置继续可用。它与赛事模式共用主题、操作界面字体、字号及语言；升级后首次启动时会从旧库提取这些界面偏好。

第一次启动新版时，将原 `data/session.json` 复制为赛事库中的一个赛事，复制它引用的照片。原会话和原照片保留。以后从赛事库打开比赛，加载该赛事自己的完整设置和进度。程序重新启动后继续上次打开的赛事。

赛事之间独立保存：

- 名称、类型、名册、队伍、照片、基准积分及统计基数。
- 新半庄起点、精算原点、顺位分、同分规则、立直棒显示及计分选项。
- 当前半庄、已归档半庄、逐局数据和淘汰赛程。
- 窗口位置、尺寸、显示开关、播出字体、直播动画、术语与快捷键。主题、操作界面字体、字号、语言和导播面板停靠动画跨赛事保留。
- 每人/每队计划场次、晋级线、榜单列显隐和顺序、自定义表头。

切换时先保存当前赛事，验证目标赛事，再完整替换设置；撤销记录、旧录牌草稿和正在播放的动画不跨赛事。原有捕获窗口继续复用，另增加独立的上方四人积分窗口；当前共12个播出窗口。

## 三种赛制

| 类型 | 日常操作 | 成绩发布 |
| --- | --- | --- |
| 团队积分赛 | 名册填写队伍编号，同队成员自动累计队伍积分 | 个人榜和团队榜；Excel包含两个工作表 |
| 个人积分赛 | 按个人累计积分排名；每人可单独设置总场次 | 个人榜；场次显示“已打/计划” |
| 个人淘汰赛 | 下方四人桌向上方四人桌晋级；每桌可打多半庄 | 个人榜、淘汰图及彩色赛程表 |

赛事库可用默认设置新建，也可在「设置来源」选择已有赛事或 JSON 设置文件。新赛事从默认四席开始，开场点数沿用所选设置。完整赛事 JSON 仍可单独导入为独立赛事。

「赛事设置 → 规则与设置文件」可导入导出赛事设置。设置文件包含规则、直播动画、版式和标识、片头、赛后背景与音乐等已保存素材。名册、赛果和进度随完整赛事备份迁移。全局偏好在导播台的「系统设置」中单独导入导出。

选中赛事后可直接查看其历史成绩，包括累计排名、已确认半庄和已保存的逐局记录。删除时须输入完整赛事名称，赛事目录中的进度、名册、成绩、备份和导出会一并清除。赛事库至少保留一场赛事。

比赛类型在创建后固定，旧赛事也不可直接更改。新建前会显示提醒；需要其他赛制时新建另一赛事。打开、新建或导入赛事前，如有未保存规则或名册，会询问保存、放弃或取消。

团队积分赛的晋级名额按全赛事队伍排名计算，个人积分赛按全体选手排名计算；不局限于当前四席。淘汰赛则使用当前赛程桌设置的晋级人数，决赛使用冠军条件。

## 赛前配置

1. 在赛事库填写赛事名称，选择类型和设置来源，再创建赛事。
2. 保存起点、精算原点、四种顺位分、同分方式和每人/每队计划场次。0表示未设总场次，榜单显示“—”。
3. 团队赛先在「队伍管理」添加并保存队伍。队伍编号自动显示，选中队伍即可选择本地队徽图片，队徽可在加入选手前保存。
4. 在「队伍管理」点击队伍颜色的色块选色，再保存队伍。添加选手后双击「所属队伍」，从已保存的队伍中选择。
5. 在「选手名册」选中一行，下方「选手资料」可编辑照片、参赛状态和颜色。点击「全部跟随队色」会立即保存当前赛事的选手颜色来源。未分队的选手会在分队后跟随队色。
6. 在「赛事设置」按页调整播出与动画、晋级、术语、统计及画面设备。

历史积分、历史场次、历史1/2/3/4位及历史最高分，只填写本软件记录之外的数据，避免重复累计。历史顺位合计不能超过历史场次。历史局数、副露、立直、和牌、放铳次数及总得失点在「赛事设置 → 统计与导出」录入。

在队伍管理中选中一支队伍，即可在侧栏预览旁编辑 **副标题（上方小字）** 和 **显示队名（主行）**。副标题留空时用单行布局，显示队名留空时使用队伍名称。预览会立即反映输入，正式展示使用已保存的设置。历史队伍积分和场次可分别留空，留空时汇总成员基数。

选中一名选手，点击 **删除 / 屏蔽选手**。没有赛事数据和队伍、席位、赛程等关联的选手可以确认删除。有数据或关联时可以确认屏蔽，从个人榜和新半庄选人列表移除，已录成绩、团队积分和当前席位保留。选中已屏蔽的选手可恢复。操作已保存的选手前，先提交名册草稿。

## 半庄确认与其他桌成绩

点击导播台左侧 **半庄管理**，直接进入“名册与场次”。页面顶部显示本半庄四人的持点、终局积分和记录状态。完成半庄终局结算后，点击 **记录本半庄积分**；记录后按钮显示“本半庄已记录”，同一半庄不重复计分。正在打的半庄不会改变正式榜单。

在下方选择当前赛事已保存的四名选手，再点击 **选择四席并开始新半庄**。团队赛可先选队伍来筛选该席选手，也可直接选人并自动带出队伍。确认当前成绩后，提前选好的四席会保留。淘汰赛使用 **前往淘汰赛程** 按桌加载下一场。

其他桌不经导播台直播时，在榜单页点击“补录其他桌成绩”：选择四人、起家和最终持点，先预览名次和pt，再确认保存。只补录成绩，不虚构逐局数据。更正补录结果使用“成绩记录与更正”，原记录被替换，不新增一场。更正使用该记录原来的计分规则。

“成绩记录与更正”中，每条半庄占两行，每行显示两名选手及各自判罚后的入账 pt；选手扣分数额和原因列在对应姓名下方，悬停可查看最终持点及判罚备注。直接对队伍的判罚列在该条记录标题下方，并标出队伍名称。记录时间为首次确认保存的本地时间，显示完整日期和时、分，更正成绩或判罚时保留原时间；旧记录缺少时间时显示“未记录”。历史成绩窗口也显示记录时间。

选中半庄后点击 **删除选中半庄记录**，核对确认后会移除该记录及其判罚，个人榜、团队榜、场次和技术统计同步更新。导播台撤销、重做不会恢复该记录。删除当前半庄记录会保留导播台的终局数据，可核对后重新记录，也可直接开始下一半庄，将该场排除在赛事成绩之外。正在播放或暂停的赛后节目会停止，累计结算画面重新读取榜单。淘汰赛如有下游桌已开赛，会阻止删除上游记录；其他情况删除后需补齐半庄并重新确认该桌晋级。

旧版提前确认后已归档的历史记录保持兼容；新版工作台的现场确认入口要求半庄结束。

### 半庄判罚

确认成绩后，可在「名册与场次」点 **本半庄判罚**，也可在「排名与结果 → 成绩记录与更正」选中历史半庄，点 **选中半庄的判罚**。登记时选择当场被判选手或队伍，填写正数扣除 pt、判罚时间、原因和选填备注。支持更正和撤销，撤销记录会保留在判罚明细中。

个人赛扣选手累计 pt。团队赛默认登记选手，扣分按其当场所属队伍汇总。对队伍的裁定可直接扣队伍累计 pt。M.League 公式战规则第 7 章按违规选手减算。产经新闻社杯的迟到规则先扣队伍分，再按本赛事规则分摊个人扣分。 [M.League 公式战规则](https://m-league.jp/about/) · [产经新闻社杯竞赛规程](https://sankeiqueen.com/about.php)

累计榜、图片、Excel 和晋级计算按该半庄的净 pt 入账。持点和当场顺位按原结算显示。普通对局撤销保留判罚，并以该半庄的原阵容为撤销边界。历史赛事的半庄详情可查看判罚明细。

## 榜单、列设置和自定义表头

在主导播台点击 **排名与结果 → 放大彩色预览**，可在独立窗口查看个人榜或团队榜。每页 36 行，用「上一页」「下一页」切换。工作台和预览同步页码。预览支持适应宽度、整页、100% 和 Ctrl＋滚轮缩放，配色及表头与导出图片一致。

个人榜提供：排名、个人昵称、队伍名称（仅团队赛事）、个人积分、场次数、平均顺位、1/2/3/4位次数、Top率、连对率、避四率、最高分。

团队榜提供：排名、队伍名称、团队积分、距第一名、距晋级线、已打/计划场次数、1/2/3/4位次数。

表头可直接拖动调整顺序，或点击“调整显示列”勾选、隐藏、上移、下移。在该窗口选中一列后可修改表头名称，也可以直接双击表头改名。排名和名称列必须保留，其位置和名称仍可调整。

**改表头只改显示名称，不改变计算字段或公式。** 个人榜与团队榜的名称分别保存，界面、Excel与PNG同步使用；其他赛事不受影响。名称为1至60个单行字符，导出会根据长度换行和调整列宽。

个人榜提供三个快捷预设：

- **赛事成绩**：上述基本成绩字段。
- **ML完整数据**：基本成绩，加总局数、平均打点、副露率、立直率、和牌率、放铳率、平均铳点。
- **技术统计**：常用技术数据，以及立直后和牌率、副露后和牌率、自摸占比、流局听牌率。

应用预设后仍可自由修改列和表头；已改好的表头名称会保留。

2026-10-27查询 [M.League官方成績表](https://m-league.jp/stats/)。官网每名选手公开18项数值指标，另有选手姓名：

| 官网指标 | 本项目字段 |
| --- | --- |
| 試合数、総局数、ポイント、平着 | 场次数、总局数、个人积分、平均顺位 |
| 1位、2位、3位、4位 | 1/2/3/4位次数 |
| トップ率、連対率、ラス回避率 | Top率、连对率、避四率 |
| ベストスコア、平均打点 | 最高分、平均打点 |
| 副露率、リーチ率、アガリ率、放銃率、放銃平均打点 | 副露率、立直率、和牌率、放铳率、平均铳点 |

本项目另提供可选的原始次数、累计得失点、自摸/荣和次数、立直后/副露后和牌率与放铳率、默听和牌占比、流局听牌率，以及立直/副露和牌的平均打点。这些为项目逐局数据可计算的扩展项，不将它们标称为官网全部公开字段。

先制立直、立直巡目、良形率、里宝牌命中率等需要当前程序尚未完整记录的逐巡或手牌信息，本版不凭空计算。

## 统计口径

报表、PNG 和 Excel 读取同一份已确认半庄数据，按半庄编号去重。当前半庄必须完成终局并确认才会上榜。「赛事设置 → 统计与导出」可查看实时技术数据。

| 项目 | 口径 |
| --- | --- |
| 个人积分/场次 | 历史基数＋每个已确认半庄结果一次 |
| 团队积分 | 按归档时的队伍归属汇总成员结果；后来换队不迁移旧成绩 |
| 团队场次 | 每队每个半庄计一次；同桌多名同队成员不会重复增加团队场次 |
| 团队顺位次数 | 每名成员的出场顺位次数，因此同队多人同桌时可超过团队场次 |
| 平均顺位 | 已知顺位的加权和/已知顺位场次 |
| Top率、连对率、避四率 | 1位/已知场次；前二/已知场次；前三/已知场次 |
| 最高分 | 已确认半庄最终持点和可靠历史最高分的最大值，单位点 |
| 距第一名/晋级线 | 本队积分减去第一名/第N名积分；负数表示落后；没有有效边界时为“—” |
| 副露、立直、和牌、放铳率 | 对应次数/已知结算局数，副露每局最多一次，暗杠不计 |
| 平均打点/平均铳点 | 累计和牌得点/和牌次数；累计放铳失点/放铳次数，含本场、不含供托 |
| 立直后/副露后和牌率或放铳率 | 有逐局明细中，对应交叉次数/立直或副露局数 |
| 自摸/默听和牌占比 | 有逐局明细中，相应和牌次数/和牌次数 |
| 流局听牌率 | 有听牌记录的流局中，听牌次数/流局次数 |

历史缺少顺位或逐局信息时，不补造记录。没有分母显示“—”，已知分母中的零次正常显示0%。Excel说明区列出覆盖范围；扩展交叉指标只用逐局明细，不借用缺乏交叉信息的历史基数。

累计积分同分时，按已确认半庄的记录顺序回算，首次达到该积分的选手或队伍排在前面。同一半庄同时达到时按该半庄的席位 1 至 4 排序，队伍取本队最靠前的出场席位。历史基数同分或旧记录缺少席位时，用名册登记顺序打破剩余同分。

## 个人淘汰赛

“淘汰赛程”可按名册顺序快捷生成四人桌，选择每桌半庄数与4进1/2/3。只有能组成完整四人桌的规模才生成；其他人数或直入后轮使用“添加四人桌”手动编排，明确选择选手或上游第N名来源。

默认桌名按全赛程连续使用A桌、B桌……Z桌、AA桌；可在“编辑选中桌”修改。后轮未决席位显示“A桌1位”“B桌2位”，晋级图、工作台与赛程Excel同步使用该来源，确认晋级后自动换成真实选手姓名。

“编辑选中桌”每席右侧的“指定选手”既可选名册选手，也能直接输入新名字。新名字加入本赛事名册并保存独立选手编号，开赛时使用该真实参赛者；原来的自动来源仍保留，清空右侧或选择“按来源自动”即可恢复。不同姓名不会覆盖旧选手或旧成绩。

先选择一桌“载入四席并开始本桌”，回到导播台操作。未直播桌可选中后补录成绩。计划半庄全部确认后，点击“预览/确认晋级”，核对名单后确认，上方桌自动取得四名选手。仍按自动来源的席位须先确认上游晋级；手动指定的席位使用导播保存的选手。

每桌晋级按本桌累计 pt 排序，同分按首次达到该积分的顺序和当时席位排序。下一桌以零携带分开始。已开赛桌可改桌名，参赛者和赛程结构锁定；已被下游引用或已有成绩的桌不能直接移除。更正上游成绩后，界面标出待核查，必须重新确认；下游已开打时禁止更换上游晋级名单。

编排、载入新桌和确认晋级作为独立的进度边界清空对局撤销栈，避免旧撤销把名册或席位退回先前轮次。成绩更正保留在原半庄ID下。

“查看晋级图”打开可独立捕获的干净窗口。图中下方为首轮，上方为后续晋级桌；每桌四行，晋级者用绿色标记。可导出完整PNG和彩色赛程Excel，个人淘汰赛事完整榜单Excel也包含赛程工作表。

## 照片与队徽

在“名册与场次”的选手表或队伍表中点击“队徽”选择图片，同队成员共用；右键可清除，保存名册或队伍后生效。队徽跟随赛事保存，并随完整赛事JSON一并导出、导入。演示队徽位于`resources/demo_team_logos/`，均为原创虚构素材，可自行替换。

播出优先显示有效选手照片；没有照片或路径失效时显示本队队徽，按完整比例居中留边。没有队徽时显示完整队名字标；没有队伍资料时显示中性标识。ML、最高位战、和牌结果、个人／团队榜单及结算、统计和走势均使用同一顺序，团队卡不会使用某位成员的个人照。历史记录保留当时保存的照片与队徽资料。

## 侧榜与听牌显示

团队赛的四席可直接在「名册与场次」顶部下拉选择。列表显示队伍与姓名，同名项附选手编号。选中后连接该赛事名册的媒体、历史基数、累计成绩与技术记录。「保存四席」用于尚未开打的本场。「选择四席并开始新半庄」用于当前半庄结束并确认后的换阵容。

侧栏“排名范围”可选择全员分页或当前四席。全员默认每页10人／队、每10秒切换，人数可设2～10、间隔可设5～60秒，切页约0.5秒淡出轻移后淡入；也可关闭自动切页后手动选页。当前四席显示本桌选手在全赛事的真实名次与已确认累计积分，不将他们重排为第1～4名。翻页只改变画面，不写入赛事成绩。顶部四人积分条仅个人赛事使用，团队赛该控件禁用。

个人／团队总表格在后台、PNG、Excel中使用整行淡队色；个人和团队侧栏普通行不使用队色底或队色条。当前上场队伍仍用原有红色整行状态标记。

“固定第一页”会切到个人全榜第1页并关闭自动翻页；页内当前上场的选手以整行红色标记，跨页仍按选手编号判断，不会把同名选手误标红。原有“当前四席”和全员轮播均保留。

导播台左侧的“侧栏快捷展示”提供可命名按钮。默认包括个人首页、个人自动轮播、当前四席和团队排名；点击即可恢复相应内容、分页设置和已保存的位置大小。“管理”可增加、保存当前显示、重命名、调整顺序或删除，全部跟随当前赛事保存；个人赛事中的团队排名预设不可用。

团队侧榜使用绿色赛事表头、深色半透明行、排名/队名/积分列。当前四席的队伍编号决定红色整行高亮，不依赖队名文字。默认每页10队，保留分页和独立窗口布局。侧栏积分保持正式已确认口径。

听牌编辑：勾选“新增待牌无役”后添加的牌变暗；已有待牌右键切换有役/无役，左键移除。勾选“振听”后，牌区背景叠加高透明度的浅草绿色。待牌、山存、无役标记和振听按“提交”一起上屏；暂时隐藏听牌保留草稿和状态，下一局、新半庄、清台会清除该局标记。

这些是人工播出标记，程序不会仅凭录入的待牌和未完整录入的手牌自动判断役或振听。

## 导出与备份

- 彩色Excel：保留数字与百分比类型、冻结表头和筛选，个人／团队总表格使用整行淡队色，负积分标红。
- PNG：全部名次和所选列排在一张完整榜单中，长名字自动增宽或换行。
- 榜单播出：干净独立窗口，页码可在榜单页切换；和Excel/PNG同一数据源。
- 完整JSON：包含照片、规则、进度、赛程、列顺序和自定义表头；在另一台电脑导入为独立赛事。

默认导出目录为当前赛事目录下的`exports/`。赛事库位于`data/library.json`，各赛事位于`data/events/<赛事编号>/session.json`及同目录`media/`。手动搬移整套赛事库时应连同全部照片目录搬移；跨电脑单场搬移优先使用完整JSON。

本版导出不依赖Excel安装或额外Python包，仍使用原来的启动方式。
