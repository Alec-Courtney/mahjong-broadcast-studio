# 赛后折线图与简易统计连播

半庄结束后，在导播台“直播快捷操作”点击 **片尾连播**，也可单独选择 **片尾走势** 或 **片尾统计**。同一行提供赛前标题、队伍介绍、本场选手、四人条件、点数走势和技术统计；共用 **暂停／继续** 与 **停止**。当前正在显示的页面按钮保持选中，连播时随实际页面变化。

再次点击已选中的页面按钮可收起该页，不会重新载入；“开场连播”和“片尾连播”保留播放动作。收起页面会关闭与它自动联动的音乐，手动独立开启的音乐继续播放。

开场连播和单独“标题”共用当前赛事的标题卡。全新安装默认显示赛事名称，可在播出设置里导入自己的图片。

程序将当前四席的点数历史、最终名次、点数、pt、立直次数、和了次数与放铳次数冻结为同一场比赛的快照。右侧人物卡分层入场，随后整体移到左侧，统计数据经色带扫入。该节目使用简易结果表。

每次点击播放或重播，都会读取当前半庄的四名选手、队名、照片、队徽、队色与结算记录。身份按选手编号关联，按本场名次排列；同一张人物卡从走势图移动到统计表。队色同时用于折线、卡片底板和统计扫带，渐变流动在当前队色基础上提亮。没有照片时使用本人所属队伍的队徽。播放期间保持快照一致，再次重播会读取最新修改。

片尾选手卡按队色生成横向渐变，队徽自动转成淡色水印并随底板一起移动。在「赛事工作台 → 名册与场次 → 队伍管理」选择队徽并保存队伍，重播即可预览。透明底队徽会保留透明区域，常见纯色底会自动淡去。

默认时间：

| 时间 | 内容 |
|---|---|
| 0–5.967 秒 | 磨砂背景、标题与坐标轴、四线错峰绘制、人物卡分层入场 |
| 5.967–20.967 秒 | 完整折线图停留 15 秒 |
| 20.967–23.967 秒 | 曲线共同擦除、坐标轴收回、卡片错峰左移、统计色带扫入 |
| 23.967–38.967 秒 | 完整简易统计停留 15 秒 |
| 38.967 秒以后 | 保持最后一页，直到手动停止或选择其他页面 |

两页停留时长可分别调整，跟随当前赛事保存，且不受对局动画速度设置影响。最终点数与本行其他主数字均以卡片中线居中；pt 独立排在点数下方，字体放大也不会将点数向上推移。

折线完整展示期间，线条内的浅色渐变继续向右流动，暂停时一同暂停。最高分点上方保留约 6% 绘图区高度。

## 声音

开场和片尾的背景音乐初始为空。选择音乐后，背景音乐与转场音效可分别开启和调音量。

1. 在「赛事设置 → 播出与动画」的赛后连播区域点击「选择音乐」，打开本地音频文件。
2. 调整音量，点击「试听音乐」预听最多 12 秒。离开该页会停止试听。
3. 点击「应用连播设置」保存。要恢复空白音乐来源，点击「清除音乐」并再次应用。

赛后绘线声在节目第 2 秒触发一次，持续 2.667 秒。其余四个过渡音也各响一次。使用标准 48 kHz 双声道 PCM16 WAV 可直接播放，MP3、FLAC 等格式使用系统上的 ffmpeg 转换。[赛后音效素材](../resources/postmatch_audio/README.md)

本机片尾优先使用 `reference/local-only/resources/postmatch_audio/` 中的标题与坐标轴（`title_axes_reveal.wav`）、绘线（`graph_reveal.wav`）、折线退场与卡片平移（`layout_sweep.wav`）音效。某个本机音效不可用时，播放器使用该位置随程序提供的合成版。

导播台的 **音乐** 按钮可独立播放已选曲目。选择了本地音乐且启用背景音乐时，开场和片尾会自动播放。手动关闭后，同一段节目翻页、暂停和结束都保持关闭。**暂停／继续** 联动当前页面与音乐，**停止** 同时收起节目并停止音乐。切换赛事、开始新半庄或退出程序时结束播放。手动独立开启的音乐会继续播放，直到主动停止。

OBS 可添加一个 **应用程序音频捕获**，选择导播控制台所属程序。OBS 30.1 及以上也支持在窗口捕获中启用捕获音频；只配置一份该程序的音频，避免重复混音。[OBS 官方音频捕获说明](https://obsproject.com/kb/application-audio-capture-guide)。

南四局和牌保留收支、和牌详情及正常退场；之后恢复选手信息。最终点数／名次、pt、本场结果和赛事总积分均由“底部显示”手动选择，确认归档不会自动切页。可根据需要反复切换。

全屏节目窗口取得焦点时：空格暂停/继续当前节目，右方向键将片尾转入统计，Esc 停止。窗口未锁定时可拖动位置，Ctrl+滚轮调整大小；位置与大小单独保存。
