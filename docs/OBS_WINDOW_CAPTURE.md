# OBS 透明窗口捕获

## 推荐设置

启动导播台，在 OBS 添加“窗口捕获”：

| 属性 | 选择 |
| --- | --- |
| 窗口 | 全屏画面选 **麻将UI · 全屏节目**；选手卡选 **麻将UI · 四家选手** |
| 捕获方式 | **Windows 10（1903 及以上）** |
| 窗口匹配优先级 | **窗口标题必须匹配** |
| 捕获客户端区域 | 开启 |
| 捕获光标 | 关闭 |

开场、赛后连播、点数走势、技术统计、四人并排条件和立直特效默认共用 **麻将UI · 全屏节目**。启动和打开赛事后，全屏内容默认透明隐藏，播放节目或主动开启相应内容后才显示。

四家选手使用 **麻将UI · 四家选手**，选手信息、个人／队伍赛事积分和结算直接在此窗口中切换，无需再捕获“赛事排名”。局况、侧边展示栏、和牌、上方积分、术语和右上角标识继续单独布置。

队伍排名、个人排名和单人晋级条件使用 **麻将UI · 侧边展示栏**，固定使用同一个竖向捕获范围。切换内容、焦点选手、当前四席／全员范围及分页都不会改变窗口名称、位置或尺寸；尺寸仍可在设置中手动调整。升级前已捕获“麻将UI · 晋级条件”的来源，请在 OBS 属性中重新选择新名称一次。

四人并排条件使用 **麻将UI · 全屏节目**。在赛事设置的晋级条件页选择“四人并排 · 全屏节目”，保存后点击“条件上屏”，或使用“四人条件（全屏）”快捷开关。单人条件未指定焦点时显示当前东家，可指定其他选手。全屏条件的显示与收起不影响侧栏排名；选择单人条件则切换侧栏内容。

升级时，旧的 1800×588 四人条件范围不再用作侧栏：优先恢复此前保存的竖向侧栏位置与尺寸，没有时采用竖向默认值。旧的短侧栏会一次性补齐固定捕获高度，保持字体与行高比例；之后切换内容或重新打开赛事不再自动伸缩。旧快捷方案中的四人条件自动转到全屏节目；侧栏快捷方案可恢复保存的位置，尺寸始终保留当前值。

| 内容 | 用途 | 默认输出位置 |
| --- | --- | --- |
| 赛后走势 | 当前半庄四位选手逐局点数折线图，可单独重播 | 全屏节目 |
| 技术统计 | 和了率、放铳率、立直率、副露率等，可选本场／累计统计或本场结果 | 全屏节目 |
| 四人并排条件 | 本桌四席各自的自摸／荣和晋级条件 | 全屏节目 |
| 赛事积分／排名 | 本桌四位选手或队伍的已确认赛事积分、名次及结算变化 | 四家选手 |

合并模式下，主动开启走势、统计或四人条件会切换到相应画面，使用同一全屏窗口的位置与尺寸。完整赛后连播仍按原时序播放走势和简易统计，声音与计分逻辑保持原有规则。

“全屏节目”的默认实际捕获尺寸为 **1920×1080 像素**，100% 对应这个尺寸，兼容 Windows 125% 等显示缩放。其他组件保持小窗口，默认大小与位置按同一张 1920×1080 画布布置。已手动调整的布局保留；可勾选“保存时恢复播出窗口默认位置”后保存，以采用全部新版默认值。

四家选手默认横跨画布宽度，内容在窗口内两侧各留 6%，底部对齐。**四家布局 → 两侧留白** 可单独调整，修改留白不会调整窗口尺寸或四家的布局坐标，积分／排名模式使用相同留白。

四家的位置会整组恢复。旧版布局迁移造成某一家错行时，会根据其余三家一致的排列修复；已经保存的自定义布局不会在每次启动时反复重排。整组移到屏幕外后，也按整组移回。

## 局况与宝牌高清捕获

局况文字和麻将牌面本身按矢量绘制。窗口捕获最终交给 OBS 的仍是像素：先用小窗口绘制，再在 OBS 中放大会损失边缘细节。

**麻将UI · 局况 · 宝牌** 现在固定提供 **2 倍像素**，例如原布局 619×121 对应捕获来源 1238×242。设置中的位置、尺寸比例和赛事保存数据仍使用原来的布局尺寸，拖动窗口也保存原来的位置；高清输出不绑定任何一份现有 OBS 布局。

- 已有 OBS 来源：窗口名称不变，升级后重新调整一次画面大小；在来源右键菜单的 **缩放滤镜** 选择 **Lanczos**。原生窗口的捕获范围扩大，是增加像素密度的正常结果。
- 新导出的 OBS 场景：局况／宝牌自动按 **50%** 放置，保持原来的布局大小；其他来源按 100%。所有导出的来源预设 Lanczos 缩放滤镜。
- 最终播出尺寸仍可在 OBS 中自由调整。需要明显更大的局况时，可同时提高程序里的尺寸比例，以提供足够的原始像素。

透明收起、重新显示、宝牌淡入和供托变化继续使用同一个高清窗口，内部布局窗口不会成为额外的 OBS 来源。

场景中缩放滤镜字段的对应关系见 [OBS 官方实现](https://github.com/obsproject/obs-studio/blob/master/libobs/obs-scene.c)。

## 和牌窗口横向留白

**麻将UI · 和牌** 的设计画布为 **1920×220**，可直接横向对齐 1920×1080 画面的两端。原来的 1840×220 内容保持原比例，左右各补 40 像素透明空间；头像原有的内部边距为 10 像素，因此头像左边缘距窗口左边 **50 像素（约 2.60%）**。头像仍为 134×200，役种与点数文字的大小及逐项显现时序保留。

测量依据为此前完整演示的和牌层：它在 1920 画面中位于 X=40、Y=840，宽 1840，因此头像实际左距为 50。单纯把旧窗口放大到 1920 宽会使头像变为约 139.8×208.7、左距约 10.4；若按两侧各留 6% 整体缩小，则头像变为约 123.0×183.7。采用增加画布宽度的方案，保留原动画中的人物和文字比例。

旧默认布局自动升级为 1920×220；手动设置过的窗口保留宽度和底部位置，按新比例校正高度，并且只迁移一次。100% 为新设计宽度，仍可在设置中按百分比等比缩放。已有 OBS 来源保持相同窗口名称，升级后可重新将其横向对齐画面两端。

## 可选拆分

在 **赛事设置 → 画面与设备 → 播出窗口** 勾选 **将全屏内容拆分为独立窗口**，点击保存，即可分别布置开场、赛后、走势、统计、四人条件和立直窗口。取消勾选并保存后恢复共用“全屏节目”。保存后设置窗口保持打开；切换输出方式保留播放进度、计分和各自的位置配置。

默认合并模式导出 8 个来源；拆分模式导出 13 个来源。拆分后的节目窗口未播放时仍为空画面，走势、统计和四人条件需主动开启。选手积分／排名始终属于“四家选手”，不随此选项拆分。

切换合并／拆分方式后，重新导出并导入对应 OBS 场景，或手动选择相应窗口来源。模式内的节目切换与收起不会更换窗口。

合并模式的全屏输出由“全屏节目”的显示开关控制，旧的开场／赛后单窗显示标记不会让其中某段节目意外变空白。立直特效是否启用仍沿用原有功能设置。

也可在程序的 **赛事设置 → 画面与设备 → 播出窗口 → 导出 OBS 窗口捕获场景** 保存 JSON，再到 OBS 的 **场景集合 → 导入**。这是一个新场景集合，含正确捕获方式和固定标题匹配，不覆盖原有集合。建议从正在使用的程序导出，让场景位置跟随当前布局。透明背景直接使用；选择绿幕／蓝幕背景时，需像原来一样在 OBS 来源上配置色度键。

## 黑屏原因与处理

本项目使用 Qt 透明原生窗口。OBS 的“自动”并不总是选择 Windows Graphics Capture：其当前实现只对部分窗口类自动选择新方式，Qt 窗口会落到 BitBlt。透明分层窗口的画面无法可靠通过该方式读取。本机 OBS 32.2.2 对同一原生透明窗口测试：BitBlt 得到不透明黑画面，Windows Graphics Capture 得到正确颜色和透明背景。因此应明确选择上表中的 Windows 10 捕获方式。

依据：[OBS 官方窗口捕获说明](https://obsproject.com/kb/window-capture-sources)、[捕获方式选择实现](https://github.com/obsproject/obs-studio/blob/master/plugins/win-capture/window-capture.c)。

## 隐藏与定位

程序内收起内容时，捕获窗口仍存在，只输出全透明空画面。重新显示内容继续使用同一窗口，不必重新选来源。窗口名称不再随语言、晋级场景等变化；严格按标题匹配可避免 OBS 将多个同类窗口混淆。完全退出程序后，来源暂时为空，重新启动后按固定标题恢复匹配。

OBS 会排除真正隐藏的窗口，这是旧版收起后难以重新定位的原因之一。依据：[OBS 窗口枚举实现](https://github.com/obsproject/obs-studio/blob/master/libobs/util/windows/window-helpers.c)。

在 **赛事设置 → 画面与设备 → 播出窗口**：

- 点击 **显示**，即时预览该窗口；关闭设置后退出临时预览，保存的显示选择正常保留。
- 点击 **定位**，即使该模块当前没有比赛内容，也显示示意内容与定位虚线。定位预览会进入 OBS，调整完关闭设置即可结束。
- 首次添加处于透明待机的“全屏节目”时，可先点“定位”让 OBS 取得画面边界，再调整位置。
- **尺寸比例** 以原始设计尺寸为 100%，宽高同比缩放；X／Y 保留位置坐标。四家布局也使用百分比，间距单独调整。

用程序内的显示开关收起内容，可保留 OBS 对窗口的匹配。
