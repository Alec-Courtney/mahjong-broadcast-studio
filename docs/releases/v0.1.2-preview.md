# Mahjong Broadcast Studio v0.1.2 Preview

发布日期：2026-11-14。此版本为Windows x64预览版，汇总自v0.1.1-preview以来的导播操作、成绩管理与播出画面更新。

## 导播台与快捷键

- “流局”“申报”“下一局”移到计分面板顶部，局况区域保留原有比赛标题及局、庄家、本场、供托编辑。
- 四位选手分别显示已播出的听牌牌面与山存量；有识别手牌时，听牌行位于手牌下方。山存量支持输入、加减及滚轮修改，保留未知与零张的区别。
- 宝牌牌面随面板宽高同比缩放。选手播出界面的听牌白边略微收窄，增大牌面内容。
- 副露预览使用与选手播出界面相同的绘制方式，直观显示横置鸣入牌、加杠叠牌及暗杠背面。点击牌面切换鸣入牌，右键移除；删除“鸣入牌为第几张”的文字说明。
- 选择“吃”时自动选中上家，仍可手动改选来源。
- 系统设置新增独立的副露、听牌牌面尺寸，40%–200%可调；原大小对应80%，新默认值为100%，即比原先放大约25%。设置即时保存并跨赛事保留，播出窗口尺寸独立设置。
- 顶栏新增“快捷键”入口，位于“工作区”左侧。“常用展示”和顶栏的显示开关改为按钮，亮色描边表示开启，不增加状态文字。移除常用展示中的“和牌画面”开关，正常结算仍会显示和牌画面。
- 撤销与恢复改为左右回转箭头；鼠标悬停显示动作和实际绑定的快捷键。默认Ctrl+Z撤销、Ctrl+Shift+Z恢复，修改或清空绑定后提示同步更新。

## 数据同步与录入修复

- 窗口重新激活或界面恢复焦点时，不再意外把宝牌输入目标切换到听牌。
- 撤销、恢复后重新读取已保存的待牌，避免旧的空草稿遮住实际听牌；听牌提交失败时保留草稿及其待提交状态。
- 各席山存量独立更新，不会提交其他待牌、无役、振听草稿，也不会改变当前操作选手。
- 放大牌面后，听牌编辑区在窄窗口中自动换行，选手面板为窗口边缘的拖动停靠保留空间。

## 逐局记录、半庄与榜单

- 导播台常驻当前半庄的逐局收支；可修改上一局或更早小局的和牌／流局结果、点数、符番、役种及供托，并重算后续收支、实时点数和技术统计。
- 支持独立于役种计算的手动收支，详情提供更正预览；记录随赛事和独立导播工作区保存。
- 改善半庄确认、历史成绩更正与删除流程；历史记录、判罚和累计榜单保持同步，避免删除的成绩被普通对局撤销恢复。
- 可编辑已确认半庄的记录日期与时间，并用于成绩列表及队伍结果展示。
- 可勾选多个已确认半庄生成队伍结果图，包含逐场成绩、队伍合计和已生效的判罚，支持整张PNG导出。
- 改善计划场次同步、排名预览缩放、团队榜单列与赛后画面排版。

## 播出画面

- 新增可配置的LIVE角标动画及位置、尺寸、停留设置。
- 改善M.League样式听牌进入／退出、山存变化动画及赛后音效衔接。
- 统一不同选手卡样式的捕获几何与缩放，改善OBS窗口捕获和布局切换的一致性。

## 下载与升级

下载附件`Mahjong-Broadcast-Studio-Windows-x64.zip`，完整解压后运行`MahjongOverlayStudio.exe`，保留同目录的`_internal`。`SHA256SUMS.txt`用于核对下载文件。

建议先从旧版“备份与说明”导出完整赛事备份，将新包解压到新目录，再导入备份继续使用。保留完整旧赛事库时，关闭旧程序后复制其`data/`及已有的`assets/imported/`到新目录同级位置，并保留旧目录作为备份。

基础包包含手动计分、赛事管理、内置演示和OBS画面输出。识别模型、OpenCV、ONNX Runtime和OBS Spout安装程序仍为按需准备的可选组件；第三方许可、运行库条款和演示肖像说明随包附带。

本版对局撤销仍只针对已保存的对局数据，不回退显示开关、主题、字号或窗口布局。记录最多60步，重启或切换赛事后清空；输入框内保留自身的撤销操作。
