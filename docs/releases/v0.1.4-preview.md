# 0.1.4-preview 更新说明

- 导播台的文字、按钮、输入框和间距同步缩放。窄窗里的立直、听牌按钮可换行，山存量输入框上方增加留白。
- 选手分数改为直接输入，按回车或离开输入框确认。移除加减按钮，滚轮和上下方向键不会改分。
- 逐局收支默认在独立窗口打开。最新一局同时显示在上方详情和下方列表首行，可从面板切换栏重新打开。
- 宝牌框的上下留白随面板高度调整，最高沿用原留白。

## Windows 更新

退出导播台后运行 `MahjongOverlayStudio-0.1.4-preview-Setup.exe`。已有安装会自动识别原目录，确认路径后继续即可。更新保留赛事、成绩、素材和设置。更新前的数据和导入素材会备份到安装目录的 `update-backups/`。

使用便携版时，可将安装目录指定为原 EXE 所在目录，在原目录更新。
