# 0.1.3：安装版兼容性与成绩更正

## 安装电脑如何更新

1. 请在直播结束后退出导播台，再运行 `MahjongOverlayStudio-0.1.3-Setup.exe`。
2. 使用原来安装软件的 Windows 账户运行。安装程序沿用 2026-11-14 安装包的应用标识，会自动找到原来的安装目录。确认界面中的目录仍是原目录即可继续。无需先卸载旧版。
3. 安装程序只替换程序、图标和内置音效，不携带旧赛事库，不覆盖 `data` 和 `assets/imported`。安装电脑后来增加的赛事、成绩、个人设置和导入素材会继续保留。
4. 更新开始前会把现有 `data` 和 `assets/imported` 复制到安装目录中的 `update-backups/before-0.1.3-日期时间/`。备份失败会停止安装。
5. 安装完成后打开导播台，核对当前赛事和最新半庄即可。不要为了更新音效重新导入 11 月 14 日的旧赛事备份；导入旧备份会恢复备份时的赛事状态。

自动识别适用于之前的安装版。如果原来直接运行便携目录中的 EXE，请把安装目录指定为该 EXE 所在文件夹，保留其中的 `data` 和 `assets/imported`。

## 音乐与音效

- WAV、MP3、FLAC、OGG、M4A、AAC 可直接选择，安装版内置解码组件。
- 修复源码版优先读取本机参考目录、而安装版使用另一套片尾音效的差异。标题、绘线、布局转换音效已统一随程序安装；赛事备份仍保存赛事设置和用户选择的音乐，内置音效由程序版本提供。
- 修复 Windows 旧音频接口拒绝较长缓存文件名导致立直无声的问题；遇到这类情况改用直接播放 PCM 的接口。播放失败原因会显示在导播台状态栏。
- 设置中的“播放立直预览”会同时播放音效，“停止预览”同时停止声音。没有增加单独的立直音效试听按钮。
- 更新程序即可更新内置音效，无需导入赛事或替换数据目录。若某首自选音乐的原文件已经丢失，进入“赛事设置 → 播出设置”的音乐选项重新选择该音乐并保存；这只更新素材引用，不修改半庄成绩。

如果本机能听见、直播中听不见，请检查 OBS 是否捕获了 `MahjongOverlayStudio.exe` 的声音。可以添加“应用程序音频捕获”，或在支持的窗口捕获来源中启用音频捕获，并检查混音器是否静音。避免同一音频同时被多路重复采集。参见 [OBS 官方应用音频捕获说明](https://obsproject.com/kb/application-audio-capture-guide)。这次没有更改正式 OBS 场景或音频设置。

## 成绩与逐局收支

- “已确认成绩与更正”中，选中半庄的两行一起高亮，离开表格焦点后仍保留颜色，并在下方显示选中记录。
- 双击半庄打开“成绩更正 / 逐局收支”窗口；原来的更正、查看按钮保留。
- 任意已确认半庄都可修改最终持点、预览并保存顺位与积分。导播录制成绩也可修改，原始逐局记录、技术统计、判罚和记录时间保留。
- 最终成绩更正不重写当时逐局发生的事实，也不改动当前导播台实时点数。逐局页面会标出最终成绩相对最后一局的差额。
- 查看导播录制的逐局收支使用与导播台相同的算法，包含本局交出的立直棒；可逐局查看结算结果、供托、交棒、局前和局后持点。仅补录最终成绩的半庄没有逐局记录。
- 编辑期间赛事或该半庄被其他窗口修改时，保存会要求重新打开核对，防止旧预览覆盖新成绩。

## 直播中找回历史局收支

点击导播台顶部常驻的“历史局收支”，会把该面板以独立窗口带回当前屏幕。关闭、移到屏幕外、原停靠区被压缩，都可以用这个入口找回。无需重新打开 UI 或重新载入工作区，不修改对局、待录入内容或播出开关。“工作区 → 组件与布局”中也提供布局及窗口管理。

## 图标

红中麻将牌、导播推杆和红色播出指示灯组成简洁图标，已应用于程序、窗口、安装包和快捷方式。提供 1254×1254 透明 PNG、256×256 PNG，以及包含 16–256 像素尺寸的 Windows ICO。
