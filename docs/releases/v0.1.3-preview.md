# 0.1.3-preview 更新与跨电脑迁移说明

本版本以 0.1.3-preview 预发布，包含全部导播台修复、独立素材备份包和安装时静默旧 JSON 转换。

## 更新另一台已经安装的电脑

1. 在直播结束后，退出导播台，运行 `MahjongOverlayStudio-0.1.3-preview-Setup.exe`。
2. 使用原来安装软件的 Windows 账户。安装程序自动识别旧版目录，确认目录正确后继续，无需先卸载。
3. 安装只更新程序、图标、解码组件和内置音效，不携带开发电脑的赛事库，不替换安装电脑后来新增的赛事、成绩、素材和个人设置。
4. 更新开始前，安装程序会保留一份更新前的 `data` 和 `assets/imported`，位置为安装目录 `update-backups/before-0.1.3-preview-日期时间/`。这是安装升级时的备份，不是日常操作生成的备份。
5. 打开新版核对当前赛事即可。本地的 `session.json` 不用转换、移动或删除；不要导入更旧的赛事备份来“更新程序”。

如果原来直接运行便携 EXE，请将安装目录指定为该 EXE 所在目录，保留原来的 `data` 和 `assets/imported`。

## 安装更新时自动转换旧 JSON

安装程序替换程序文件后，会自动调用主程序内置转换逻辑，处理原安装目录中的赛事存档和旧备份。扫描范围包括根目录 JSON，以及 `data/`、`exports/`、`legacy-backups/`、旧导入文档目录和演示目录中的赛事 JSON。普通索引、全局设置和其他非赛事 JSON 不参与转换。转换不会扫描电脑其他目录，也不修改安装前的回退备份。

在每个原 JSON 旁生成同名 `.mjbackup`；原 JSON 和素材保留。重复更新覆盖同名包，不创建编号副本。安装结束前完成转换，结果记录在 `data/backup-migration-0.1.3-preview.json`。如果有缺失素材导致转换失败，安装程序会提示原因，保留原文件供修复后重试。

转换只在安装更新时静默执行，不提供单独转换 EXE，也没有应用内手动转换按钮或入口。需要一并转换的安装目录外旧备份，可先放到原安装目录的 `legacy-backups/` 中，再运行安装更新。正常转换不弹出界面。

将 `.mjbackup` 复制到目标电脑，在新版“赛事管理 → 导入完整赛事备份包”中导入为独立赛事。对外完整赛事及赛事设置导入只接受 `.mjbackup`；本地实时 `session.json` 仍正常保存和监听，不需要删除。系统全局设置仍可单独交换。

包内赛事、逐局记录、半庄成绩和图片、音乐分别保存。音乐不再挤占旧 JSON 的 32 MiB 素材总限额。详见 [备份包结构](../BACKUP_PACKAGE_FORMAT.md)。

## 素材托管与缓存

导入的照片、队徽、Logo、标题卡、背景和音乐继续复制到项目 `assets/imported/`。相同内容去重；重复导入、修改点数或调整设置不会层层复制同一原始素材。历史记录仍使用的旧素材保留。

音乐在启动和更换选曲后后台预热既有解码缓存，不自动播放。日常操作不会额外生成赛事备份包。手动再次导出到同一文件会更新原包；失败则保留旧包。

## 点数监听系统

现有比分同步助手仍使用原程序和原配置，监听同一个 `session.json`，四席 ID、实时持点、局况和立直显示口径不变。更新不需要部署服务器或更换上传密钥。迁移到另一台电脑后，在助手里重新选择目标电脑实际数据目录即可；不要选择 `.mjbackup` 作为实时监听文件。

## 同时包含的导播台修复

- 支持 WAV、MP3、FLAC、OGG、M4A、AAC；安装版内置音频解码。
- 统一源码版与安装版片尾音效，修复立直长缓存文件名被 Windows 旧播放接口拒绝的问题，播放失败会显示原因。
- 设置中的原有立直预览同时试听音效，没有增加独立试听按钮。
- 已确认成绩选中后整条高亮；双击打开“成绩更正 / 逐局收支”，原有按钮保留。
- 可更正任意已确认半庄的最终成绩，保留原始逐局记录、判罚、历史资料和记录时间；逐局收支包含本局交出的立直棒。
- 顶部常驻“历史局收支”可找回被关闭或移到屏幕外的面板，直播中无需重启 UI。
- 新的红中麻将牌与导播推杆图标已用于程序、安装包和快捷方式。

如果本机试听正常、OBS 没有声音，请检查是否采集 `MahjongOverlayStudio.exe` 的应用音频，以及混音器静音和监听设置；更新程序不会改动正式 OBS 场景。参考 [OBS 官方说明](https://obsproject.com/kb/application-audio-capture-guide)。
