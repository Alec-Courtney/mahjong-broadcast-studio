# 0.1.3-preview 验证记录

- 85 个独立应用测试模块，907 项全部通过。
- 计分引擎、逐局引擎和同步网页合计 37 项检查通过。
- 现有独立比分同步组件 13 项检查通过；没有部署或修改线上服务器。
- 新包以 34 MiB 音乐验证移除旧素材总量限制，原素材目录移走后仍能完整导入。

- 原比分监听适配器读取升级后的实时 JSON，输出与升级前相同；会话版本和路径保持兼容。
