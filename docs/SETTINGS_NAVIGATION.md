# 设置与赛事入口

主导播台直接提供 **赛事管理**、**半庄管理**、**排名与结果**、**本桌选手资料** 和 **系统设置**。

| 入口 | 用途 |
| --- | --- |
| 赛事管理 | 赛事库、赛事规则、名册与场次、排名与结果、淘汰赛程、备份 |
| 半庄管理 | 直接打开“名册与场次”，核对本半庄持点、记录赛事积分，选择四席开始下一半庄 |
| 排名与结果 | 直接打开个人／团队排名，查看或更正已确认成绩，导出图片与 Excel |
| 本桌选手资料 | 当前四席的姓名、头像、队伍、颜色与点数 |
| 系统设置 | 后台主题、语言、导播台字体与字号、设置页字号、导播面板停靠动画及全局设置文件 |

赛事标识左侧快捷区用于编辑下段文字。上段文字、Logo 和字号在 **Logo 设置** 中修改。选择或清除 Logo 会立即保存到当前赛事，文字和版式使用该窗口的 **保存**。

在设置和赛事窗口里，数字框与下拉框使用点击或键盘调整。滚轮可用于浏览页面。

## 设置分类

- **系统设置**保存跨赛事使用的界面偏好。导播台和设置页字号支持 9–24 px，调整后即时保存。
- **赛事管理 → 赛事设置 → 规则与设置文件**管理计分规则、计划场次、晋级名额和赛事设置文件。新建时可在赛事库选已有赛事或设置文件作为来源。
- **播出与动画**管理开场、直播动画速度、立直特效、赛后连播停留与音乐、标识、侧栏和积分条。切换赛事会恢复各自的播出设置。
- **晋级条件、术语与字幕、统计与导出**在同一工作台内分页管理。
- **画面与设备**管理捕获窗口、选手卡、播出字体、识别来源、布局与快捷键。

独立导播模式通过 **工作区 → 独立播出设置** 管理当前导播工作区的播出和计分配置。

## 保存和关闭

- 设置、赛事工作台、详细播出、四家布局、快捷键、选手资料、Logo、术语按钮、侧栏方案及榜单列设置，点击各自的 **保存** 后保留窗口，可继续修改。
- 关闭、Esc 或退出程序前有未保存改动时，询问 **是否保存设置**，提供 **是／否**。是：保存成功后关闭；否：丢弃尚未保存的改动后关闭。此前已经保存或立即执行的操作不会被撤回。
- 没有未保存改动时直接关闭。保存失败、字段无效或发生冲突时，显示原因并留在原窗口，不会静默关闭。
- 赛事和详细播出窗口提供 **保存修改**，保存本窗口各页的待保存表单；也可继续使用页内保存按钮。播放、上屏、导入和开始比赛等明确操作仍立即执行。
- 播出窗口和四家布局的尺寸均输入百分比，100% 为相应窗口的原始设计尺寸，宽高同比缩放；位置和四家间距仍单独输入。已有像素布局继续兼容，保存无关设置不会改变原有尺寸。
- 四家布局的比例、位置、联动和缩放按钮先修改草稿，点击保存后应用。
- 四家选手共用一个捕获窗口。显示开关即时提供临时预览，也可点“定位”显示边界；关闭设置后恢复正常播出。窗口保持存在，隐藏内容时输出透明空画面。OBS 的捕获方式与场景导出见 [OBS 窗口捕获](OBS_WINDOW_CAPTURE.md)。
- 开场、赛后连播、点数走势、技术统计和立直特效默认共用“全屏节目”，默认实际输出 1920×1080，空闲时透明隐藏；可勾选“将全屏内容拆分为独立窗口”并保存，之后分别布置。其他组件按 1920×1080 画布保留各自的小窗口。
- 赛事积分、排名和结算在“四家选手”中切换。四家布局可以分别调整位置、尺寸、间距与两侧留白。
- 浏览卡片样式、预览选手、文字或背景选项不算设置修改。保存后没有实际改动时直接关闭；未完成的数字输入仍会提醒保存。
- 主设置只写实际编辑的字段，保留其他窗口已保存的未编辑字段；同一字段冲突时要求重新读取。切换赛事或导入会话后，旧主设置草稿仍禁止保存，重新读取后才可继续。
