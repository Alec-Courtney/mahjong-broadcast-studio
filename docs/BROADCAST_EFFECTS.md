# 播出场景与动画

通过「赛事管理 → 赛事设置」调整当前赛事的开场、直播动画、侧栏、术语字幕和赛后节目。「系统设置」管理导播界面主题、字号和面板动画。 [设置入口](SETTINGS_NAVIGATION.md)

## 开场与赛事标识

- 在「播出与动画」选择标题卡，预览后点击「播放完整开场」。团队赛四席分属四队时，节目依次显示标题卡、四队名单、本场选手，再衔接四席入场。
- 导播台的「赛事标识」可快捷编辑文字。「Logo 设置」提供 Logo、比例和位置，以及上下两段文字的字号和字间距。设置页同时提供标识预览。
- 标题卡和 Logo 按原比例绘制。导入后保存在项目素材库，完整赛事 JSON 可以携带使用中的素材。 [素材迁移](EVENT_DATA_STORAGE.md)

## 选手卡与立直

在「赛事设置 → 画面与设备 → 播出显示」选择 M.League 或保留版最高位战样式。播出字体、透明度和四家布局由当前赛事保存。

对局中声明立直时，动画显示选手所属队伍的队徽与队色，没有队徽时显示该队名称。每项约 2.5 秒，多人声明按点击顺序播放。每个声明保留入队时的队伍资料，画面在该声明完成后展示扣棒和选手卡状态。账本按当前赛事计分规则处理。

设置页的「播放立直预览」可选当前四席之一并播放一次。换页或切换赛事会结束预览。

## 侧栏、晋级条件与术语

- 侧边栏可显示个人或队伍排名，也可显示单人晋级条件。范围、翻页和切换内容使用同一窗口尺寸。
- 四人并排晋级条件使用全屏节目。自动条件依据当前赛程、晋级名额和计分规则计算，也可以填写手动条件。两个版式可在「晋级条件」预览。
- 上方积分的自动模式在两把制淘汰桌显示本桌首把已确认 pt，尚未确认时显示横线。其他场次使用已确认累计 pt。「上方积分」可在播出设置中单独选择模式。
- 「术语与字幕」可选常用术语或填写自定义文案。标题和正文可分别调整字体、字号和字间距。预览沿用实际播出时的换行和排版。 [词库及字幕](COMMENTARY_GLOSSARY.md)

## 终局与赛后

终局后在「底部显示」手动选择最终点数、结算 pt、本场结果或赛事总积分。M.League 样式在收支出现后将浮字垂直汇入点数，立直棒与普通点数可在局末分别展示。

「片尾连播」使用同一份已结算四席数据展示走势和简易统计。赛事可分别设置两页停留时间、背景和声音。 [赛后连播与试听](POSTMATCH_PLAYBACK.md) · [OBS 捕获](OBS_WINDOW_CAPTURE.md)
