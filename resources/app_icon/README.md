# 应用图标

由内置图像生成工具生成，结合红中麻将牌、三根导播推杆和红色指示灯。背景外沿透明。

- `mahjong_broadcast.png`：1254×1254 原图。
- `mahjong_broadcast_256.png`：256×256 PNG。
- `mahjong_broadcast.ico`：16、24、32、48、64、128、256 像素。

生成提示要点：简洁 Windows 应用图标，深青色圆角方形底，象牙白麻将牌和红色“中”，下方深蓝导播台搭配三根浅色推杆与一枚红色指示灯，正面构图，无其他文字和水印，小尺寸可辨。

PNG 缩放与 ICO 封装保留原图透明度，没有额外绘制或重做图案。
